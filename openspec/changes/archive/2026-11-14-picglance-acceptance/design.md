## Context

逐条验收旧版规格和实现，并核验设计、真实文件、Windows 行为和性能。

## Goals / Non-Goals

本包完成联调与验收，公共接口定义和应用接线归基线 owner。

## Decisions

- 核对 G1 证据，执行资源管理器打开 → 翻图 → 编辑 → 另存 → 压缩。
- 覆盖旧规格逐项验收矩阵和实现额外功能，记录冲突处置。
- 在 Windows 上核验安装、升级、卸载、便携、关联、键盘与 100%/150%/200% DPI。
- 对照旧版记录运行首图、稳态内存、超大图峰值、翻图、动图及两类包体测试，汇总 G2。
- 覆盖旧版 12 份规格、两个归档变更及源码。旧 README 的 46 MB 便携记录与规格冲突，验收沿用 30 MB 规格。实测分别记录主进程与 WebView2 进程树。

## Risks / Trade-offs

- 把真实 Windows 环境差异、失败场景与证据写入交接。
