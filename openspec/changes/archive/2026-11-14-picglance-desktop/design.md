## Context

迁移设置、系统主题、语言、托盘、单实例、关联、右键打开、便携、安装卸载、日志及更新检查。

## Goals / Non-Goals

本包完成Windows 集成与设置，公共接口定义和应用接线归基线 owner。

## Decisions

- 完成设置页、三种关闭行为及主题/语言接线，验证便携 INI 与安装版配置隔离。
- 完成单实例参数转发和传统右键菜单，验证带空格与中文路径。
- 实现每用户关联注册、默认应用引导、快捷方式与卸载清理。
- 打包安装版和便携 ZIP，验证升级保留数据、日志轮转及 GitHub Releases 提示。
- Windows 默认应用由用户通过系统界面选择。分别验证已有 WebView2、联网补装和离线场景。

## Risks / Trade-offs

- 把真实 Windows 环境差异、失败场景与证据写入交接。
